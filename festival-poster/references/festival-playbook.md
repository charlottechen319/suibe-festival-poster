# 节日内容手册

选节日 → 查表得：日期 / 英文 / 色系 / 花木 / 天象 / 印章 / 文案。
表里没有的节日，按第 6 节的“推断规则”处理。

> 日期以 2026–2027 年为主。农历节日、节气每年浮动，**出图前必须复核**（见 §5）。

| 代号 | 形态 | 适用 |
|---|---|---|
| `plum` | 五瓣梅，枝干折转，雪中更佳 | 冬、春节、元旦、小寒、大寒 |
| `osmanthus` | 桂花小簇 + 椭圆绿叶 | 中秋、秋分、教师节 |
| `ginkgo` | 扇形银杏叶，金黄 | 秋分、霜降、重阳 |
| `maple` | 五裂枫叶，橙红 | 寒露、霜降、深秋 |
| `chrys` | 细瓣菊，金黄 | 重阳、秋分 |
| `pine` | 松针，墨绿 | 圣诞、冬至、大雪 |
| `willow` | 垂柳，嫩绿 | 清明、春分、谷雨 |
| `none` | 不画花木，只留山水 | 极简、国庆、纯文字海报 |

### 天象（`celestial`）

| 值 | 效果 | 适用 |
|---|---|---|
| 默认（太阳） | 低角度暖阳 + 光晕 | 大多数节日 |
| `moon` | 冷白满月 + 淡青光晕 | 中秋、元宵、七夕、寒露 |

## 4. 文案库

### 4.1 印章（2 字）

`节气` `佳节` `节日` `端午` `中秋` `重阳` `冬至` `校庆` `毕业` `感恩`

### 4.2 四字短语（可做竖联或副标）

春：`万物始生` `东风解冻` `春和景明` `草长莺飞`
夏：`绿荫幽草` `蝉鸣夏长` `荷风送香` `竹露清响`
秋：`金风送爽` `丹桂飘香` `层林尽染` `月满中秋`
冬：`岁暮天寒` `围炉煮雪` `梅香如故` `静待春归`
通用：`岁序更新` `万象更新` `山河锦绣` `国泰民安` `人间烟火` `岁月长安`

### 4.3 五/七言竖联（公版诗句为主）

- 中秋：`海上生明月` / `天涯共此时`
- 重阳：`每逢佳节倍思亲` / `遍插茱萸少一人`
- 冬至：`天时人事日相催` / `冬至阳生春又来`
- 清明：`清明时节雨纷纷` / `路上行人欲断魂`
- 端午：`彩线轻缠红玉臂` / `小符斜挂绿云鬟`
- 元宵：`火树银花合` / `星桥铁锁开`
- 七夕：`金风玉露一相逢` / `便胜却人间无数`
- 春节：`爆竹声中一岁除` / `春风送暖入屠苏`
- 教师节：`师泽如光` / `微以致远`
- 国庆：`盛世华诞` / `举国同庆`

> 竖联优先用 5–7 字；4 字时把字距加大到 0.5em，避免视觉太短。

## 5. 日期复核

农历节日、节气、母亲节/父亲节/感恩节等浮动日期，**不要凭记忆写**。

推荐顺序：

1. 用 `web_search` 查“2026 年 <节日> 是几月几日 农历”；
2. 优先中国天文年历、紫金山天文台、权威万年历；
3. 交叉验证 2 个来源；
4. 农历日期写“农历冬月十四”这类中文，不写数字；
5. 无法确认时，只写公历日期，省略农历行（版式允许）。

固定日期（可直接用）：元旦 1/1、情人节 2/14、妇女节 3/8、植树节 3/12、劳动节 5/1、青年节 5/4、建党 7/1、教师节 9/10、国庆 10/1、校庆 10/11、平安夜 12/24、圣诞 12/25、万圣 10/31。

## 6. 表外节日的推断规则

### 6.1 先定季节

- 3–5 月 → `spring` + `willow`；
- 6–8 月 → `summer` + `lotus`；
- 9–11 月 → `autumn` + 当季花木；
- 12–2 月 → `winter` + `plum`。

### 6.2 再定气质

- 家国/喜庆/纪念 → `red` + `none` 或 `plum`；
- 思念/传统/文人 → `ink` + `willow`/`chrys`；
- 校园/青春/毕业 → `spring` 或 `autumn` + `ginkgo`/`osmanthus`；
- 西方节日 → 保留水墨语法，换符号：圣诞用 `pine`，情人节用 `rose`（若无 rose，用 `plum` 代替），感恩节用 `maple`。

### 6.3 英文名

- 优先用官方/通用英文名；
- 长度 > 17 字符自动两行（模板已实现）；
- 没有通用英文名时，用拼音（如 `QIXI FESTIVAL`）+ 中文主标题。

### 6.4 文案

- 不硬造空洞口号；优先公版诗句、成语、四字短语；
- 竖联与节日要有真实关联（花、月、气候、习俗）；
- 一张海报只讲一个情绪：团圆 / 思念 / 致敬 / 迎春 / 登高。

### 6.5 没有把握时

- 用最安全的组合：`ink` 色系 + `plum`/`willow` + 四字短语 + 公历日期；
- 宁少勿多：一枚印、一条联、一枝花即可。
