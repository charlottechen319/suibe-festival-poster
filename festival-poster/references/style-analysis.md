# 上经贸大研究生会 · 节日海报视觉规律分析

> 样本：`~/Desktop/节日海报/` 内 6 张海报（国庆、教师节、重阳、寒露、中秋、秋分）。
> 分析目的：提炼可复用的“风格 DNA”，不是复刻任何一张原图。

---

## 0. 一句话结论

这组海报的共同公式是：

**一张暖白宣纸 + 一座淡墨远山 + 一枝应季花木 + 一个巨大的毛笔节日名 + 一行 Didone 英文 + 一条竖排小联 + 一枚朱砂小印 + 底部固定的校徽横式组合。**

它们看起来“高级”的原因不在元素多，而在三件事：

1. **纸感统一**：所有画面都像印在同一批手工纸上，底色、噪点、暖度一致；
2. **层级克制**：远景、中景、近景最多三层，颜色种类少，靠明度和虚实拉开；
3. **字压得住画**：书法标题永远是画面最黑、最大、最有笔锋的部分，插画只做它的背景。

## 1. 配色规律

### 1.1 底色：不是白色，是“暖宣纸”

| 海报 | 纸底取样 | 说明 |
|---|---|---|
| 国庆 | `#F7CCB2` 附近（霞光） | 全幅暖霞，纸底被红光覆盖 |
| 教师节 | `#F9EFDE` / `#F8ECDC` | 奶油米白，最暖 |
| 重阳 | `#F8F2E6` / `#FAF5E9` | 标准宣纸白 |
| 寒露 | `#F5F7FA` / `#EBEEF2` | 唯一的冷调纸，雾蓝白 |
| 中秋 | `#FBF5E7` / `#FCF8EF` | 月白，偏奶 |
| 秋分 | `#F7F0E2` / `#FBF6EC` | 暖米白 |

**结论**：
- 默认纸底取 `#F7F1E4` 到 `#FBF6EC`，明度 94–97%，饱和度 8–15%；
- 不用纯白 `#FFFFFF`，也不用纯米黄 `#F5E6C8`（会显旧）；
- 冷调节日（寒露、大雪、冬至可选）用 `#EDF1F3`，但保留一点暖灰，避免医院感；
- 全画面叠加 3–6% 的纸纤维噪点 + 8–12% 的四周暖色暗角。

### 1.2 墨色：不是纯黑，是“松烟墨”

| 用途 | 取样 | 说明 |
|---|---|---|
| 书法主标题 | `#0B0B0B`–`#24231F` | 大面积近黑，带一点褐/蓝 |
| 正文/对联 | `#3C3A34` | 比标题浅一档 |
| 英文刊头 | `#3A3730`（60–90% 不透明） | 与纸底拉开但不抢书法 |
| 远山 | `#8FA3AD` / `#AEBCC2` | 墨被水冲淡的灰蓝 |
| 近山 | `#5C6C6E` / `#617276` | 仍不是黑 |

**结论**：画面里没有纯黑；最深的一档只留给书法和极小面积的印。

### 1.3 三种强调色系统

这 6 张海报其实只有三套强调色，按节日气质切换：

**A. 秋香金 / 赭石（教师节、重阳、中秋、秋分）**
- 金：`#D9A441`、`#E0B23C`、`#E8B84B`
- 赭：`#8B5E3C`、`#775D42`
- 叶绿：`#5E6C4A`、`#6D7A55`
- 用于银杏、桂花、书本、暖阳、窗光。

**B. 朱砂红 / 暖霞（国庆、中秋印章）**
- 朱砂：`#B43C2C`、`#BB1213`、`#C0392B`
- 暖霞：`#EFBFAD`、`#F7CCB2`
- 只用于红旗、印章、少量飘落花瓣；**不大面积铺在标题上**（国庆除外，它是主题色）。

**C. 冷墨青 / 雾蓝（寒露，也可用于大雪、冬至）**
- 远：`#C7CED4`
- 中：`#8FA3AD`
- 近：`#5C6C6E`
- 只做环境色，强调色仍是朱砂印 + 一点暖阳。

### 1.4 面积配比

一张海报大致遵循：

```
纸 / 中性色   60–70%
墨（字 + 山） 15–20%
强调色        8–12%
印章 / 高饱和 2–3%
```

**判断标准**：眯眼看，画面应该是一张“米白纸 + 一块黑字 + 一小点红/金”。如果强调色超过 15%，就会从“新中式”掉到“节庆模板”。

### 1.5 季节映射（可复用）

| 季节 | 纸底 | 远山 | 强调 | 花木 | 光 |
|---|---|---|---|---|---|
| 春 | `#F7F4E8` | `#BCC7B9` | 桃粉 `#D98A86`、柳绿 `#8B9A5E` | 柳、桃、玉兰 | 清晨冷白光 |
| 夏 | `#F4F5EC` | `#AEC4C0` | 荷粉 `#D98A9A`、艾绿 `#5F7F57` | 荷、竹、石榴 | 正午偏白，或雨后 |
| 秋 | `#F8F1E2` | `#C8B99F` | 金 `#D9A441`、赭 `#8B5E3C` | 银杏、桂花、菊、枫 | 低角度暖阳 |
| 冬 | `#F7F3EA` | `#AEBCC2` | 朱砂 `#B43C2C`、冷蓝 `#8FA3AD` | 梅、松、枯枝 | 低日 + 冷雾 |
| 喜庆 | `#F9EADC` | `#C98D6F` | 正红 `#B01F1F`、金 `#D8A03C` | 灯笼、梅、绸 | 暖霞、逆光 |

## 2. 插画质感规律

参考图是 AI 绘画/数字绘景，不是矢量插画。要保留“质感”，需要复制的是**材质逻辑**，不是具体山形。

### 2.1 纸：一切质感的底

- 米白纸底 + 细密纤维噪点（不是电视雪花，是宣纸的短纤维）；
- 大面积轻微色斑（茶渍/水痕），透明度 3–6%；
- 四角暖色暗角，中心略亮；
- 所有元素都像“印”在纸上，而不是“贴”在纸上：边缘有 1–2px 的柔化，颜色略透纸。

### 2.2 墨：五档灰，湿边，飞白

- 山不是单色块，而是 3–5 档墨：远山 15–25% 不透明，中山 30–40%，近山 45–55%；
- 山脊边缘有“湿边”：比山体深 10–15%，宽 2–3px，轻微模糊；
- 山体内部有横向/斜向的干笔纹理（树影、皴法），透明度 5–10%；
- 书法有飞白和涨墨：笔画边缘不光滑，起笔重、收笔枯。

### 2.3 水：透明叠加，不靠渐变

- 水彩感来自“多层半透明色块叠加”，不是一条从 A 到 B 的线性渐变；
- 色块边缘有 2–6px 的洇开；
- 同一区域最多叠 3 层，超过就脏；
- 水面用横向拉长的倒影 + 少量竖向光斑，不用镜面反射。

### 2.4 光：一个低角度暖光源

- 6 张里 5 张有明确的太阳/月光：位置多在画面 55–75% 高度，偏右；
- 光源周围有 150–250px 的柔光晕；
- 逆光物体有 1–2px 的亮边（树枝、花瓣、建筑檐口）；
- 阴影长、软、偏冷（蓝灰），不是黑色。

### 2.5 雾：分层，不是滤镜

- 远山与中山之间、中山与校园之间各有一条横向雾带；
- 雾带用 40–70px 模糊的白色椭圆，透明度 50–80%；
- 越远越灰、越蓝、越模糊；越近越暖、越实；
- 雾是“空气透视”的工具，不是白纱。

### 2.6 景深：三层，近景要虚

- 远景：山、雾、天空，对比 20–35%；
- 中景：校园/建筑/桥/湖，对比 40–55%；
- 近景：花枝、书、石头，对比 70–90%，其中**前景一角通常虚化 6–10px**（中秋右下角的花枝、教师节左下角的书）。
- 虚实关系让画面“有镜头感”，这是参考图高级的关键之一。

### 2.7 校园：只做中景剪影

- 中秋、教师节、秋分都出现了上经贸大校园元素：钟楼、教学楼、桥、湖、综合楼；
- 处理方式：低对比（30–45%）、轻雾、局部暖窗光、**不画细节**；
- 校园是“身份暗示”，不是主体；主体永远是节日和书法。

### 2.8 细节密度：一处密，大片空

- 每张海报只有一个“密”的区域：右上花枝 / 左下书本 / 底部校园；
- 其余区域保持安静；
- 不要平均撒装饰，那会变成素材拼贴。

## 3. 留白规律

### 3.1 留白比例

实测 6 张海报的“无内容纸面”大约占 **40–55%**。其中：

- 国庆：约 35%（红旗占面积大）；
- 教师节：约 45%；
- 重阳：约 50%；
- 寒露：约 55%（最空）；
- 中秋：约 40%；
- 秋分：约 42%。

**结论**：默认目标 45–50%。低于 35% 会闷，高于 60% 会空。

### 3.2 四个留白区

```
┌──────────────────────────────┐
│  A 标题区（左上，最安静）      │  B 日期区（右上，小）
│                              │
│  C 呼吸区（中左，允许山/雾）   │  D 花木区（右侧，可密）
│                              │
│        校园 / 湖 / 雪         │
│  E Logo 区（底部中央，干净）   │
└──────────────────────────────┘
```

- **A 区**：英文 + 书法标题，背景只允许极淡的纸/雾，不能有花；
- **B 区**：日期 + 农历，最多一条 1px 细线；
- **C 区**：書法右侧到画面中线，保持 200–300px 的“呼吸带”；
- **D 区**：花枝/书本/灯笼，可以密，但不超过画面 1/3；
- **E 区**：Logo 上方 100–140px 内不要放高对比元素。

### 3.3 非对称

- 标题永远在左，花木永远在右（或右下），形成一条从左上到右下的对角线；
- 不用居中大标题（除了 Logo），不用左右对称；
- 视觉重量：左 40% 字，右 35% 画，中 25% 空。

## 4. 排版规律

### 4.1 画布与网格

- 画布：**1080 × 1920**（9:16），参考图多为 941×1672 / 1080×1920；
- 安全边距：**64px**（约 6%）；
- 12 栏网格，栏宽 64px，槽 24px；
- 基线 8px，所有字号取 8 的倍数（近似即可）。

### 4.2 字体角色

| 角色 | 字体 | 字号（1080 宽） | 颜色 | 位置 |
|---|---|---|---|---|
| 英文刊头 | Didot / Bodoni 72 / Bodoni Moda | 96–150（长词自动缩） | 墨 90% | 左上，距顶 74，距左 62 |
| 书法主标题 | 毛笔行楷（马善政/汉仪尚巍手书类） | 280–340 | 墨 100% | 左 82，顶 352，竖排 |
| 公历日期 | Didot / Bodoni | 52 | 墨 75% | 右上，距顶 246，距右 64 |
| 农历 | 宋体 Light | 27 | 墨 65% | 日期下，字距 0.16em |
| 竖联 | 宋体 Light | 33 | 墨 80% | 右 66，顶 1024，竖排 |
| 印章 | 宋体 Medium | 17 | 纸白 | 书法右中，46×64 |
| Logo 名称 | 宋体 Light/Regular | 36–37 | 墨 90% 或纸白 | 底部中央 |

### 4.3 英文刊头：Didone 的“高对比”

- 参考图用的是 Didot/Bodoni 一类现代衬线：横细竖粗、球状收笔、字距略开；
- 全大写，一行或两行；两行时第二行略短，形成阶梯；
- 颜色比书法浅一档，避免抢主标题；
- 与日期同处右上时，日期在英文下方，不并排。

### 4.4 书法标题：大字压阵

- 2 字：约 330px/字，占左侧 38% 宽、50% 高；
- 3 字：约 280px/字；
- 4 字：约 236px/字；
- 字与字之间不完全对齐：左右错位 ±15px、旋转 ±1.5°，模拟手写；
- 起笔/收笔要有轻重变化，不能像电脑字库直接排版；
- 标题永远是画面最黑的部分。

### 4.5 日期：小而准

- 公历：`2026/12/22` 或 `12/22`，Didot，字距 0.04em；
- 下方 1px 细线（透明度 30%），长度等于日期块宽度；
- 农历：`农历冬月十四`，宋体，字距 0.16em，字号约公历的一半；
- 位置：右上，距右 64，距顶 246；两行英文时下移到 306。

### 4.6 竖联：一条安静的竖线

- 2 列，右列在前（竖排从右往左读）；
- 5–7 字/列，字号 33，字距 0.34em，行距 1；
- 两侧各一条 1px 竖线（透明度 26%），线高等于文字高度；
- 位置：右 66，顶 1024；不居中，不与日期同高；
- 内容用现成诗句/四字短语，不硬造口号。

### 4.7 印章：唯一的高饱和

- 尺寸 46×64（参考图约 36×50）；
- 朱砂红底，纸白字，2 字竖排（节气/佳节/节日）；
- 圆角 4–6px，旋转 2–3°；
- 位置：书法第一、二字之间的右侧，不压住笔画；
- 每张海报最多一枚。

### 4.8 Logo：固定版式（硬规则）

参考图 6 张里有 5 张是**底部居中**的横式组合（秋分为左下变体）。固定规格：

```
[校标 109×75]  22px  [上海对外经贸大学研究生会 37px / 字距 0.38em]
←———————— 总宽约 700px ————————→
                 底部距边 58–70px
                 水平中心 = 画布 50%
```

- 校标用学校“知识门 + 书页”图形，橙色 `#F67A14`（官方色 `#FC770C`）；
- 校标与文字**垂直居中对齐**，文字不要比校标高；
- 文字用宋体 Light/Regular，字距 0.36–0.40em，颜色墨色（深底用纸白）；
- Logo 下方、上方各留至少 40px 干净纸面；
- 不改比例、不加阴影、不描边、不放进花丛里。

- 都有：纸感、墨色、低饱和、一个暖光源、植物/校园、书法标题、宋体小字、橙色校标；

- 英文有无、一行/两行；
- 日期在右上/左下/无；
- 竖联在右/左/无；
- 书法 2/3 字；
- 强调色金/红/冷蓝；
- 校园元素的多少。

**不变的只有**：纸、墨、字、印、校徽版式。

## 6. 可复用配方（生成时按顺序）

1. **定季节**：春/夏/秋/冬/喜庆 → 纸底、山色、强调色、花木、光。
2. **定构图**：左字右画，或上字下景；标题区留空 40%。
3. **铺纸**：纸底 + 噪点 + 暗角 + 色斑。
4. **画远山**：3 层，冷灰蓝，雾带分隔，山脊湿边。
5. **放校园**：中景剪影，30–45% 对比，局部暖窗。
6. **画近景**：一枝应季花木，从右上/右下入画，前景可虚化一角。
7. **打光**：低角度暖阳/月，柔光晕 + 逆光边。
8. **排字**：英文 → 书法 → 日期 → 竖联 → 印章。
9. **压角标**：底部居中 Logo，固定规格。
10. **调色**：整体降饱和 5–10%，加 3–6% 颗粒，检查留白 45%。

## 7. 明确不要做的事

- 不要直接使用参考图的任何一张作为背景或拼贴素材；
- 不要把 6 张的元素全部堆在一张上；
- 不要用纯黑 `#000` 大面积写字；
- 不要用 3 种以上强调色；
- 不要把标题居中，或把 Logo 放进花丛/建筑里；
- 不要用硬边矢量山、扁平渐变天空、无纹理的纯色块；
- 不要用宋体/黑体直接排书法标题（必须用毛笔字库或手写生成）；
- 不要把校园画成写实建筑效果图（它只是中景剪影）；
- 不要让英文比中文标题更抢眼（英文是刊头，不是主标题）。
