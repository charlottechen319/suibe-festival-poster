## 3. 组件坐标

所有坐标为元素外接框左上角，单位 px。

| 组件 | left | top | right | bottom | 说明 |
|---|---|---|---|---|---|
| 英文刊头 | 62 | 74 | 自动（右不超 1020） | — | 单行 96；超 958px 自动缩到 ≥48 |
| 日期块 | — | 246 | 64 | — | 双行英文时 top=306 |
| 日期细线 | — | 日期下 14 | — | — | 1px，透明度 32% |
| 书法 | 82 | 352 | — | — | 竖排，字间距 0 |
| 印章 | 书法左 + 0.94×字号 | 书法顶 + 0.58×字号 | — | — | 46×64，旋转 2.4° |
| 竖联 | — | 1024 | 66 | — | 两列，右列在前 |
| 竖联线 | 竖联左右各 1px | 与文字同高 | — | — | 透明度 26% |
| Logo 组合 | 50% 居中 | — | — | 58 | 见 §4 |

### 3.1 书法错位

每个字加轻微手写错位，避免“字库感”：

| 字序 | translateX | rotate |
|---|---|---|
| 1 | −3 px | −1.3° |
| 2 | +15 px | +0.9° |
| 3 | −11 px | −0.7° |
| 4 | +7 px | +1.1° |

### 3.2 竖联

- `writing-mode: vertical-rl`，`text-orientation: upright`；
- 两列用 `flex-direction: row-reverse`，DOM 第一列显示在右侧；
- 列间距 26px，左右各 26px 内边距，外侧 1px 竖线；
- 建议 5–7 字/列；4 字时字距可加到 0.5em，避免太短。

### 3.3 日期

```
2026/12/22          ← Didot 52
────────────        ← 1px，透明度 32%，上下 14/12
农历冬月十四         ← Songti 27，字距 .16em
```

- 右对齐；
- 公历与农历之间必须有细线（参考图 4/6 有）；
- 没有农历时可只留公历，细线保留。

```
┌─────────────── 总宽 ≈ 700px ───────────────┐
│                                             │
│   ┌────────┐   22px  上海对外经贸大学研究生会  │
│   │ 校标   │        36px / 字距 .36em       │

│                                             │
└─────────────────── bottom 58 ───────────────┘
```

| 项 | 值 |
|---|---|
| 校标 | 高度 96 px，宽度自适应（官方 PNG 约 143×96） |

| 校标资产 | `assets/logo-mark-official.png`（从用户提供的 logo 原图抠出，透明底） |
| 间距 | 22 px |
| 名称 | 上海对外经贸大学研究生会（11 字，宋体） |
| 名称字号 | 36 px |
| 名称字距 | 0.36em（≈13px） |
| 名称颜色 | 浅底 `#23201B`，深底 `#FDF8EF` |
| 组合高度 | 82 px |
| 水平 | 画布中心（left 50%，translateX(-50%)） |
| 垂直 | 距底 58 px（参考图 58–70） |
| 保护 | 上方 120px、下方 40px 内不得有高对比元素 |

**变体**：秋分式左下角版本仅用于画面右下角被花木完全占满时；默认必须居中。不要改成竖排、不要只放图形、不要给名称加粗黑体。

## 5. 色彩 Token

| Token | 默认 | 用途 |
|---|---|---|
| `--paper` | `#F7F1E4` | 纸底 |
| `--paper-deep` | `#ECE1CF` | 纸底暗部/暗角 |
| `--ink` | `#24272A` | 书法、主标题 |
| `--ink-soft` | `#3C3A34` | 对联、日期 |
| `--accent` | `#B43C2C` | 印章、少量花瓣 |
| `--gold` | `#C99A4B` | 秋季辅助 |
| `--logo-orange` | `#F67A14` | 校标 |
| `--logo-ink` | `#2C2924` | Logo 名称 |

规则：

- 一屏最多 1 个强调色 + 1 个辅助色；
- 强调色面积 ≤ 12%；
- 印章是唯一 100% 饱和的色块；
- 文字不用纯黑，插画不用纯白。

## 6. 构图的三种合法变体

### A. 经典（默认）
- 英文左上、日期右上、书法左中、竖联右下、Logo 居中；
- 适合：节气、重阳、中秋、教师节。

### B. 无英文 / 纯中文
- 去掉英文，日期右上，书法左中，竖联左侧或右侧；
- 适合：中秋、元宵、春节等传统节日（参考图 5/6 张无英文或弱英文）。

### C. 大英文
- 英文 1–2 行占满顶部，日期下移，书法略下移；
- 适合：秋分、重阳、元旦等有强英文名的节日。

不论哪种变体，**Logo 版式不变**。

## 7. 验收清单

渲染后逐项检查：

- [ ] 画布 1080×1920（导出 2160×3840）
- [ ] 纸底不是纯白，四角有轻微暖暗角
- [ ] 书法标题是画面最黑、最大的元素
- [ ] 英文没有压到日期/花木
- [ ] 日期 + 农历 + 细线齐全，右对齐
- [ ] 竖联 5–7 字/列，两侧有 1px 竖线
- [ ] 印章只有一枚，位于书法右侧，不压笔画
- [ ] Logo 居中、距底 58、校标 109×75、名称 36px/字距 .36em
- [ ] Logo 周围 120px 干净
- [ ] 留白 40–55%
- [ ] 强调色 ≤ 2 种，面积 ≤ 15%
- [ ] 放大 200% 看：画面有纸纹/颗粒，边缘不是硬矢量
- [ ] 没有直接使用参考图
